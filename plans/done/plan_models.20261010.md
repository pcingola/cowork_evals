# plan_models

The typed models the assessments in [`plan_tests/`](plan_tests.20261010) need. This file is the one source for every model's fields and types. Read with [`plan_tests.md`](plan_tests.20261010.md), whose "Decisions" table settles the open points.

`?` marks an optional field. On write, an optional field that is `None` is absent, never null, unless the row says otherwise. A field with a default that the row says is "written only when" a condition holds is absent otherwise. `(key)` after a field is its on-disk key where it differs from the field name. "Existing" means a class in `src/cowork_evals/` today that the row extends instead of adding a new one. Each model replaces the synonyms in its first column.
